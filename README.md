
# UCM Marvel - Universo Cinematográfico

## Descripción del proyecto

UCM Marvel es una página web dedicada al Universo Cinematográfico de Marvel (UCM). Su objetivo es presentar información sobre algunas de sus películas, sus héroes, las fases cinematográficas y los próximos estrenos.

El sitio cuenta con un diseño visual relacionado con el universo Marvel y permite navegar fácilmente entre sus diferentes secciones.

## Objetivos

- Presentar películas destacadas del Universo Cinematográfico de Marvel.
- Mostrar información sobre las fases 1, 2 y 3 del UCM.
- Organizar algunas películas en una tabla con su año de estreno, fase y género.
- Presentar una tabla de próximos estrenos.
- Incorporar un carrusel de imágenes interactivo.
- Facilitar la navegación mediante un menú de enlaces.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página web.
- **CSS3:** estilos, colores, diseño y presentación visual.
- **JavaScript:** funcionamiento del carrusel de imágenes.

## Características principales

### 1. Menú de navegación

Permite acceder a las diferentes secciones de la página:

- Inicio
- Películas
- Fases
- Tabla de películas
- Próximos estrenos

### 2. Carrusel de imágenes

Incluye tres diapositivas con imágenes relacionadas con el universo Marvel.

Sus funcionalidades son:

- Cambio automático de imagen cada 5 segundos.
- Botón para pasar a la diapositiva siguiente.
- Botón para regresar a la diapositiva anterior.
- Indicadores para seleccionar una diapositiva específica.
- Reinicio del temporizador cuando el usuario cambia la diapositiva manualmente.

### 3. Películas destacadas

Presenta tarjetas informativas de algunas películas y personajes del UCM, como:

- Los Vengadores
- Guardianes de la Galaxia
- Doctor Strange

Cada tarjeta contiene una imagen, un título, una descripción y un enlace de navegación.

### 4. Fases del UCM

Describe las tres primeras fases del Universo Cinematográfico de Marvel:

- **Fase 1:** presentación de los héroes y formación de los Vengadores.
- **Fase 2:** expansión del universo y aparición de nuevos personajes.
- **Fase 3:** grandes conflictos que conectan las historias de diferentes héroes.

### 5. Tabla de películas

Organiza algunas películas del UCM con la siguiente información:

- Nombre de la película.
- Año de estreno.
- Fase correspondiente.
- Género.

### 6. Próximos estrenos

Incluye una tabla con títulos anunciados o previstos para los próximos años, como Avengers: Doomsday y Avengers: Secret Wars.

Las fechas mostradas son orientativas y pueden cambiar.

### 7. Pie de página

Contiene información del proyecto académico, una sección de contacto y enlaces a las redes sociales oficiales de Marvel.

## Instalación y ejecución

1. Descarga o copia los archivos del proyecto en una carpeta.
2. Comprueba que las carpetas `css`, `js` e `images` tengan los nombres correctos.
3. Verifica que las imágenes existan y coincidan con las rutas utilizadas en el HTML.
4. Abre el archivo `index.html` en un navegador web.
5. Navega por las secciones y comprueba el funcionamiento del carrusel.

No se necesita instalar software adicional para visualizar la página localmente en un navegador moderno.
